  U2  TWO-VIEWS-DISAGREE  both readable and different -> CELL: name the writer between them.

3. STALENESS (by value, fixed now)
====================================================================================================
  This kernel prints no in-log epoch: the XNU console lines are `[os-console-...]`/`[RTCLOCK]`, never
  `[<sec>.<frac>]` (measured on the 1037 capture: 0 such lines).  The kernel's own `uptime_s` row is
  run-relative and states no wall time; it is printed for the host to check the SPLIT, not to date the
  capture.
  Therefore the capture's boot is anchored by its FILE MTIME, i.e. the moment recover_last_kmsg.sh
  read /proc/last_kmsg of the boot AFTER this press (a press does not return; the operator's
  power press boots the installed ROM; that boot's last_kmsg is the run).  The checker requires
  mtime (or an in-log wall stamp, should one appear) >= the press's boot epoch, else
  `NO READING - STALE SLOT`, exit 2.  Never the `-YYYYMMDD-HHMMSS-` name stamp (when TAKEN).

  The relaunch precondition (from 1037): the 1037 run's launchd faulted a few seconds after boot and
  STAYED DEAD (no re-scan, up to 10 s).  If 1039's run does NOT re-fault after the instrumented
  capture, the launchd launch loop is not spinning and the capture is a report, not a cell.
