WHY H-OTHER IS A PROBE DEFECT, NOT A THIRD HYPOTHESIS (by value).
  The pre-registered H2 cell (docs/1026-design.md s.4) reads:
      H2 : lookup_far=0 AND far_in_map=1 AND entry_hi == far AND map == taskmap
  Three of its four conjuncts are MEASURED TRUE: lookup_far=0, far_in_map=1, map==taskmap.
  The fourth, `entry_hi == far`, is UNREADABLE BY CONSTRUCTION: the publisher writes
      trap.c:878  printf("xnu_live_abt_entry_hi=0x%08x\n", (_abt_hit && _abt_e) ? _abt_e->vme_end : 0);
  i.e. entry_lo/entry_hi are printed only when `_abt_hit` is TRUE — which is exactly FALSE in the
  H2 case (`lookup_far=0`).  In the H2 case the covering entry is in `_abt_e2` (the far-4 lookup),
  NOT in `_abt_e`; but the publisher reads `_abt_e`, so it prints 0.  So the H2 cell demands a value
  the probe is built never to emit when H2 is true: the cell is INTERNALLY CONTRADICTORY.
  => the H-OTHER verdict is a FAIL-CLOSED ARTIFACT of the instrument.  The by-value physics names
  H2's mechanism, but the probe cannot print H2's confirming conjunct.
